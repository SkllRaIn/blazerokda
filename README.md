# 🚗 Автосервис «АС-Авто» — Коммерческая ERP-система и Студия Онлайн-Записи

Полнофункциональная коммерческая веб-платформа для автоматизации сети СТО, шиномонтажей и автосервисов. Включает в себя интерактивный мастер бронирования услуг, личный кабинет клиента с авторизацией по Email+Паролю, админ-панель для контроля записей, поддержку СУБД **MariaDB** с автоматической синхронизацией данных и безопасный эквайринг платежей.

---

## 🛠️ Ролевая Архитектура Системы

1. **Гость**: Может просматривать список услуг, выбирать филиал СТО на интерактивной карте, использовать промокоды, рассчитывать стоимость ремонта автомобиля и оплачивать визиты онлайн.
2. **Личный кабинет клиента** (*Новое*): Полноценная регистрация и авторизация (Email + Пароль + ФИО + Телефон). Предоставляет постоянный доступ к истории визитов, статусам работ по машине (в работе, завершена) и быстрой выписке товарных чеков/квитанций на печать.
3. **Панель Администратора**: Позволяет управлять прайс-листами, редактировать адреса СТО, добавлять промо-акции, фильтровать и переводить заявки из статуса в статус по воронке, а также экспортировать отчет в формат CSV.

## 📂 Техническая Спецификация и Назначение Файлов

### Командные & Системные файлы конфигурации:
* **`/package.json`** — Менеджер зависимостей Node.js. Содержит скрипты для компиляции TypeScript-сервера с помощью `esbuild` во временный исполняемый CJS-артефакт для максимальной скорости холодных стартов.
* **`/tsconfig.json`** — Параметры сборщика TypeScript, строгие проверки (`strict: true`), подавление неиспользуемых параметров для обеспечения стабильности и безопасности типов в MariaDB.
* **`/vite.config.ts`** — Конфигурационный файл сборщика Vite, оптимизирующий бандлинг React-клиента, отключающий HMR для бесконфликтной интеграции с Dev Server.
* **`/metadata.json`** — Метаданные приложения в AI Studio, системные разрешения (камера, микрофон, геолокация) и перечисление аппаратных возможностей.
* **`/.env.example`** — Шаблоны переменных окружения для продакшн-сервера (подключение к СУБД, секретные ключи подписи JWT, секрет вебхуков ЮKassa).
* **`/.gitignore`** — Фильтр файлов, предотвращающий утечку локальных хранилищ, логов, бинарных сборок и паролей (`node_modules`, `dist`, `db.json`, `.env`).

### Архитектура Фронтенда (React + Tailwind CSS):
* **`/src/main.tsx`** — Главная точка входа клиентской части, монтирующая корневой React-компонент в DOM.
* **`/src/index.css`** — Единый файл глобальных стилей с директивой `@import "tailwindcss";`. Задает цветовую гамму, шрифтовое сглаживание и переменные бренда.
* **`/src/types.ts`** — Строгая типизация сущностей ERP (Филиалы, Услуги, Записи, Промокоды, Пользователи СУБД, Клиенты). Обеспечивает согласованность API фронтенда и бэкенда.
* **`/src/App.tsx`** — Корневой компонент интерфейса. Рендерит интерактивный лендинг, навигационную панель статуса авторизации клиента, акции с живым таймером обратного отсчета, отзывы и контакты.
* **`/src/components/BookingWizard.tsx`** — Модуль пошаговой записи (Выбор филиала ➡️ Выбор услуги ➡️ Дата/Время ➡️ Параметры автомобиля ➡️ Промокод на скидку ➡️ Оплата/Внесение предоплаты через mock-терминал эквайринга).
* **`/src/components/CustomerCabinet.tsx`** — Кабинет зарегистрированного клиента. Обрабатывает регистрацию и вход на JWT-токенах, безопасно сохраняет сессию в `localStorage`, выводит интерактивную таблицу визитов со статусом выполнения и чеками для распечатки на принтер.
* **`/src/components/AdminPanel.tsx`** — Рабочее место менеджера СТО. Позволяет оперативно подтверждать записи, управлять прайс-листом автосервиса, редактировать координаты филиалов, скачивать Excel/CSV выгрузки.

### Системный Бэкенд (Node.js + Express):
* **`/server.ts`** — Сервер высокой готовности. Выполняет следующие задачи:
  1. **Интеграция СУБД MariaDB**: Инициализирует пул соединений `mysql2/promise`, автоматически создает необходимые таблицы при первом старте сервиса, синхронизирует in-memory кэш и физическую БД.
  2. **Регистрация & Авторизация на bcrypt-подобных хэшах**: Подписывает безопасные JWT-токены с ограничением жизненного цикла сессии.
  3. **Защита Эндпоинтов**: Верифицирует входящие заголовки авторизации.
  4. **Безопасность Вебхуков ЮKassa**: Проверяет подлинность уведомлений о платежах, вычисляя криптографическую подпись HMAC-SHA256, защищая кассу СТО от мошеннических подмен.

## 💾 Схема Базы Данных MariaDB

Система автоматически генерирует в базе данных MariaDB 8 связанных таблиц:
1. `as_config` — Системные настройки СТО (наименования, цвета интерфейса, адреса связи).
2. `as_branches` — Координаты и контакты филиалов автосервиса.
3. `as_services` — Каталог видов работ (ремонт подвески, замена масла, детейлинг) с ценами.
4. `as_bookings` — Журнал записей транспортных средств с указанием госномера, марки автомобиля, выбранного таймслота, внесенной предоплаты, а также статуса (принят, в работе, готов).
5. `as_promotions` — Таблица активных купонов на скидку.
6. `as_reviews` — Отзывы автовладельцев с бальной оценкой.
7. `as_admins` — Администраторы и мастера-приемщики СТО.
8. `as_customers` — Учетные записи зарегистрированных клиентов (пароли хранятся в зашифрованном виде PBKDF2/SHA255).

## 🚀 Настройка и Локальный запуск

1. **Скопируйте пример файла конфигурации**:
   ```bash
   cp .env.example .env
   ```
2. **Задайте параметры подключения в `.env`**:
   ```env
   DB_HOST=localhost
   DB_PORT=3306
   DB_USER=as_auto_user
   DB_PASSWORD=strict_database_password
   DB_NAME=as_auto_db
   JWT_SECRET=strong_system_jwt_key
   YUKASSA_SECRET_KEY=yookassa_webhook_security_signature_key
   ```
3. **Запустите сервер в режиме разработки**:
   ```bash
   npm run dev
   ```
   Сервер запустится на порту `3000` с автоматическим запуском клиентского SPA-приложения во встроенном iframe AI Studio.
